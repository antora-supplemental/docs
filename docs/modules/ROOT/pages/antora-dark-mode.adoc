= Antora Dark Mode
:navtitle: Antora Dark Mode

Dark mode supplemental UI for Antora's default UI bundle: theme toggle, FOUC prevention, and CSS overrides.

For composed doc-site chrome (mast, header, layout), see link:https://github.com/antora-supplemental/valentus-theme[valentus-theme].

[NOTE]
====
Full install steps, configuration, and the live demo are documented on link:https://antora-supplemental.github.io/antora-dark-mode/[GitHub Pages (canonical)^].
This org hub uses a green-themed shell so it stays visually distinct from that product site.
====

The https://github.com/antora-supplemental/docs[antora-supplemental/docs] hub aggregates *multiple* organization projects.
