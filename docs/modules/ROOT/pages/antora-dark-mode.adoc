= Antora Dark Mode
:navtitle: Antora Dark Mode

Dark mode supplemental UI for Antora's default UI bundle: theme toggle, FOUC prevention, and CSS overrides.

For composed doc-site chrome (mast, header, layout), see link:https://github.com/antora-supplemental/valentus-theme[valentus-theme].

[NOTE]
====
Full install steps, configuration, and the live demo are documented on link:https://antora-supplemental.github.io/antora-dark-mode/[GitHub Pages (canonical)^].
This org hub uses a green-themed shell so it stays visually distinct from that product site.
====

== Successor to `antora-dark-theme`

The former monolithic **`antora-dark-theme`** package was split:

* *Full stack (usual install):* link:https://github.com/antora-supplemental/valentus-theme[valentus-theme] release `ui-bundle.zip` (chrome + bundled dark mode)
* *Dark mode only (overlay):* link:https://github.com/antora-supplemental/antora-dark-mode[antora-dark-mode] on top of your own `ui.bundle`

Canonical homes are the **antora-supplemental** org repositories above.
Personal forks of the old package name are obsolete leftovers — do not treat them as the source of truth.
Migration steps: link:https://antora-supplemental.github.io/antora-dark-mode/antora-dark-mode/guide/legacy-names.html[Legacy names & migration^] in the dark-mode guide; Valentus has the matching install section for full-stack sites.
Org-wide product map: xref:theme-products.adoc[Theme products].
